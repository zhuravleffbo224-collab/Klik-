# 3KLIK — GitHub Pages demo

Это статический демонстрационный сайт. Для публикации не нужны Node.js, сборка, сервер или установка библиотек.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Откройте репозиторий GitHub, в который хотите загрузить сайт.
3. Загрузите **содержимое папки `3klik`** в корень репозитория. В корне должны лежать `index.html`, `style.css`, `app.js`, `.nojekyll` и `favicon.svg`.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
7. Дождитесь публикации и откройте адрес GitHub Pages, который покажет GitHub.

Если публикуете сайт из папки `/docs`, загрузите туда все файлы сайта и выберите `/docs` в настройках Pages.

## Что работает

- Переходы между разделами и навигация браузера «назад/вперёд».
- Создание демонстрационных coin-концептов.
- Выбор рынка, Long/Short и условного leverage.
- Предварительный просмотр и загрузка изображения.
- Поиск, сортировка и карточки созданных концептов.
- Статистика и локальное сохранение в браузере.
- Информационные разделы, модальное окно и внешние ссылки.

## Важные ограничения текущей версии

Это frontend-demo: созданные концепты хранятся в `localStorage` конкретного браузера и устройства. Они не синхронизируются между посетителями и не попадают в общую базу данных. Если очистить данные сайта в браузере, локальные записи могут исчезнуть.

Подключение криптокошелька, выпуск токенов в Solana, реальные сделки, платежи, общая база пользователей и серверная статистика не реализованы. Для этого понадобятся backend и интеграция с соответствующими сервисами. Кнопки таких действий намеренно отключены или показывают уведомление о демо-режиме.

Сайт использует Google Fonts как необязательное улучшение. Если шрифты недоступны, включаются системные.
